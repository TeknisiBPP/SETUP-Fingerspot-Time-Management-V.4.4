# Fingerspot Time Management V4.4

Panduan untuk mengunduh dan melakukan instalasi aplikasi Fingerspot Time Management V4.4 melalui GitHub.

## 1. Membuka Repository

Buka repository GitHub Fingerspot Time Management V4.4.

Setelah halaman repository terbuka, pastikan berada pada halaman utama repository seperti pada gambar berikut.

## 2. Membuka Release

Pada bagian sebelah kanan halaman repository, cari bagian:

`Releases`

Kemudian klik release:

`FTM V4.4`

Release tersebut berisi file aplikasi yang dapat digunakan untuk instalasi.

## 3. Download File Aplikasi

Setelah halaman `FTM V4.4` terbuka, scroll ke bagian:

`Assets`

Kemudian klik file aplikasi dengan format `.zip` untuk memulai proses download.

Contoh:

`FTM-V4.4.zip`

Tunggu hingga proses download selesai.

## 4. Extract File

Setelah file ZIP selesai di-download:

1. Buka folder tempat file ZIP tersimpan.
2. Klik kanan pada file `FTM-V4.4.zip`.
3. Pilih `Extract All...`.
4. Pilih lokasi folder untuk menyimpan hasil extract.
5. Klik `Extract`.

Pastikan seluruh file aplikasi sudah berhasil diekstrak ke dalam satu folder.

## 5. Menjalankan Installer

Buka folder hasil extract.

Cari file installer aplikasi dengan format `.exe`.

Klik kanan pada file installer tersebut, kemudian pilih:

`Run as administrator`

Jika muncul konfirmasi Windows, pilih `Yes`.

## 6. Proses Instalasi

Ikuti petunjuk instalasi yang muncul pada layar.

Pada proses instalasi:

1. Pilih lokasi instalasi jika diperlukan.
2. Ikuti instruksi yang diberikan oleh installer.
3. Tunggu hingga proses instalasi selesai.
4. Setelah selesai, klik `Finish`.

## 7. Menjalankan Aplikasi

Setelah instalasi selesai, buka aplikasi Fingerspot Time Management V4.4 melalui shortcut yang tersedia di Desktop atau Start Menu.

Jika aplikasi tidak dapat dibuka, coba klik kanan pada aplikasi kemudian pilih:

`Run as administrator`

## 8. Konfigurasi Aplikasi

Setelah aplikasi berhasil dibuka, lakukan konfigurasi sesuai kebutuhan.

Pastikan pengaturan aplikasi, database, dan perangkat absensi sudah sesuai sebelum aplikasi digunakan.

## Catatan

- Pastikan file ZIP sudah di-extract sebelum menjalankan installer.
- Jangan menjalankan aplikasi langsung dari dalam file ZIP.
- Jangan menghapus file yang terdapat di dalam folder hasil extract jika masih diperlukan oleh aplikasi.
- Jika Windows menampilkan peringatan saat menjalankan installer, pastikan file yang digunakan berasal dari repository resmi.
- Jika mengalami kendala saat proses instalasi atau konfigurasi, silakan hubungi tim support Fingerspot.
