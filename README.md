# Fingerspot Time Management V4.4

## Panduan Instalasi

### 1. Download Aplikasi

Download file `FTM-V4.4.zip` yang tersedia pada repository ini.

### 2. Extract File

Setelah file selesai di-download:

1. Klik kanan pada file `FTM-V4.4.zip`.
2. Pilih `Extract All...` atau gunakan WinRAR/7-Zip.
3. Extract file ke folder yang diinginkan.
4. Pastikan seluruh file hasil extract berada dalam satu folder.

### 3. Jalankan Aplikasi

Buka folder hasil extract, kemudian cari file aplikasi FTM dengan format `.exe`.

Klik kanan pada file `.exe`, kemudian pilih:

`Run as administrator`

Tunggu hingga aplikasi terbuka.

### 4. Konfigurasi

Setelah aplikasi berhasil dibuka, lakukan konfigurasi sesuai kebutuhan.

Pastikan seluruh pengaturan yang diperlukan sudah sesuai sebelum aplikasi digunakan.

### 5. Selesai

Jika aplikasi sudah berhasil dibuka, maka proses instalasi telah selesai dan aplikasi siap digunakan.

## Catatan

- Jangan menjalankan aplikasi langsung dari dalam file ZIP.
- Pastikan file ZIP sudah di-extract terlebih dahulu.
- Jangan menghapus file yang terdapat di dalam folder aplikasi.
- Jika aplikasi tidak dapat dibuka, coba jalankan menggunakan `Run as administrator`.
- Jika masih mengalami kendala, silakan hubungi tim support.
